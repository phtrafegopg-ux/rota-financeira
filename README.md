# Rota Financeira

Aplicativo experimental de controle financeiro para motoristas de aplicativos. Projeto PWA, com atualização por GitHub Actions e GitHub Pages.

⚠️ Ambiente de testes. Não publicar dados financeiros pessoais, prints ou backups neste repositório.

**Status:** etapa técnica da beta privada publicada. O lançamento público/comercial continua condicionado às validações externas e operacionais documentadas.

- [Abrir o aplicativo](https://phtrafegopg-ux.github.io/rota-financeira/).
- [Entrega, evidências e limites](docs/ENTREGA-BETA-PRIVADA.md).
- [Guia de desenvolvimento e comandos verificados](AGENTS.md).
- [Roteiro de homologação física](docs/BETA-PRIVADA.md).

Antes de atualizar uma instalação com dados, guarde um backup criptografado fora do repositório e feche as abas antigas. A senha do cofre é indispensável para restaurá-lo. Copiar o código para o PC não transfere seus dados nem sincroniza o aplicativo instalado.
